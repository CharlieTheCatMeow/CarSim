# CarSim
A car simulation. ~~Want to add neural engine maybe~~ Added a neural engine

## Installation and how to use
[Link here](https://github.com/CharlieTheCatMeow/CarSim/releases/tag/v1.0.0)

Just download the exe and run it. 

There's also a brain.npz file that contains some pre-trained weights for the neural engine. 
Put it in the same folder as the executable, and you can load it in the options menu.

Also, you can press ESC to enter a pause menu to access the rest of the menus.

## Features:
- Tweak the car's stats
- Change the amount of cars on the track
- Change the track (there's a couple presets)
- Some other stuff

## Useful keybinds:
- H: Show only the best car
- 1, 2, 3, 4: Change the simulation speed
- ESC: Enter the pause menu
- R: Jump to the next generation
- P: Drive on the track yourself
